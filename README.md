# Rail_Arm_Theory
Rail Arm Theory Primes Filtering
Author: Marc Roberge

As a subset of the CCH framework, also by Roberge, the Rail Arm Theory describes a novel concatenative prime number sieve with tail operator and type preference layer tuning increasing likelihood pools of prime dense clusters in the number line can be identified more efficiently.
